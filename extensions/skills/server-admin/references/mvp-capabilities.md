# MVP Capabilities

## Read tools

- `get_guild_summary`
- `list_categories`
- `list_channels`
- `list_roles`
- `get_member`
- `list_members_by_role`

## Write tools

- `create_role`
- `assign_role`
- `remove_role`
- `create_text_channel`
- `archive_channel`
- `move_channel_to_category`
- `post_announcement`

## Out of scope for the current MVP

- bans
- kicks
- channel deletion
- mass role updates
- broad permission rewrites
